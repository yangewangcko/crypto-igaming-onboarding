Card Payouts

The Card Payouts solution enables you to send money directly to recipients' cards in real-time, using direct integrations with Visa Direct and Mastercard MoneySend, which support both domestic and cross-border payouts.

Card Payouts is available for businesses incorporated in:

  • European Economic Area (EEA)
  • Singapore
  • United Arab Emirates
  • United Kingdom (UK)
  • United States of America (USA)

Types of card payouts

There are two types of card payouts.

Card Payout

You can perform Card Payouts for the following Funds Transfer Type categories:

  • Money transfers
  • Non-money transfers
  • Online gambling

Apple Pay Card Payout

The Apple Pay Card Payout solution enables you to perform payouts to eligible cards with Apple Pay on the following platforms and minimum OS versions:

  • iOS 17.0
  • iPadOS 17.0
  • Mac Catalyst 17.0
  • visionOS 1.0

Integration guide

The payout integration guide for merchants.

Preparation: Key scopes

CKO has assigned key scopes (vault:card-metadata, balances, forex) to API Keys in sandbox.

Merchant: For the production environment, please raise a support ticket via the Dashboard or send an email to with the Key IDs of the Private API Keys and/or OAuth Keys (for forex) you are using, and ask the team to add the above scopes to the keys.

Process

  1. Endpoint: POST /metadata/card
    • format = card_payouts
    In the response, check eligibility based on the different fund transfer types:
    • Visa: money_transfer (FT/LA), non_money_transfer (FD)
    • Mastercard: money_transfer (C52), non_money_transfer (C55)
  2. Endpoint: GET /balances
    Check if you have enough funds. Amount = Available + Pending + Operational.
  3. (If needed) Endpoint: GET /forex/rates
    • product = card_payouts
    Update frequency:
    • Visa: Daily @ midnight UTC
    • Mastercard: Daily @ 22:00 UTC
  4. Endpoint: POST /payments
    • source.type = currency_account

Required fields

  • Currency Account ID (ca_) — used as the source.id field in the /payments endpoint. Found in the Dashboard (Entity level) → Business account → Balances. Click the … icon on the Currency Account to open the Account details popup.
  • Entity ID (ent_) — used in the /balances endpoint. Found in the Dashboard (Entity level) → Settings (upper-right corner) → Account details.

In the /payments endpoint:

  • instruction.funds_transfer_type:
    • FD/FT/LA for Visa
    • C52/C55 for Mastercard
    Value may be different in sandbox vs production.
  • processing_channel_id — found in the Dashboard → Settings (upper-right corner) → Settings → Business settings → Processing channels.
  • destination.account_holder.type = individual
  • sender is required for Money Transfer (FT/LA/C52) — the sender is the user:
    • sender.type = individual
    • sender.first_name = user's first name
    • sender.last_name = user's last name
    • sender.address = user's billing address
    • sender.reference
    • sender.reference_type = other
    • sender.source_of_funds = debit

Domestic vs cross-border

All countries are enabled in the sandbox environment, but please refer to the countries list we provide for the production environment.

  • A Card Payout is Domestic when the entity's country of incorporation is the same as the recipient issuer country.
  • A Card Payout is Cross-border when the entity's country of incorporation is NOT the same as the recipient issuer country.

[Production] Internal validation:

  1. Non-money transfer (sender is the merchant): check if the recipient issuer country is part of the destination countries list (see country list Excel — to be shared by the CKO team).
  2. Money transfer (sender is the user): check if the recipient issuer country is part of the destination countries list, and check if the sender billing country is part of the sender countries list (see country list Excel — to be shared by the CKO team).
