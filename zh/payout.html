卡片提现

卡片提现 解决方案使您能够通过与 Visa Direct 和 Mastercard MoneySend 的直接集成，实时将资金直接发送到收款人的卡片， 并同时支持境内和跨境付款。

卡片提现适用于在以下国家或地区注册成立的企业：

  • 欧洲经济区（EEA）
  • 新加坡
  • 阿拉伯联合酋长国
  • 英国（UK）
  • 美利坚合众国（USA）

卡片提现的类型

卡片提现有两种类型。

提现到银行卡

您可以针对以下资金转账类型类别执行卡片提现：

  • 资金转账
  • 非资金转账
  • 在线博彩

提现到 Apple Pay

Apple Pay 卡片提现 解决方案使您能够在以下平台及最低操作系统版本上，通过 Apple Pay 向符合条件的卡片执行付款：

  • iOS 17.0
  • iPadOS 17.0
  • Mac Catalyst 17.0
  • visionOS 1.0

集成指南

面向商户的出金集成指南。

准备工作：密钥权限范围

CKO 已在沙盒中为 API 密钥分配了密钥权限范围（vault:card-metadata、balances、forex）。

商户：对于生产环境，请通过控制台提交支持工单，或发送邮件至 并附上您正在使用的私有 API 密钥和／或 OAuth 密钥（用于 forex）的 Key ID，请团队将上述权限范围添加到这些密钥上。

流程

  1. 端点： POST /metadata/card
    • format = card_payouts
    在响应中，根据不同的资金转账类型检查资格：
    • Visa：money_transfer（FT/LA）、non_money_transfer（FD）
    • Mastercard：money_transfer（C52）、non_money_transfer（C55）
  2. 端点： GET /balances
    检查您是否有足够的资金。金额 = 可用 + 待处理 + 运营。
  3. （如有需要）端点： GET /forex/rates
    • product = card_payouts
    更新频率：
    • Visa：每日 UTC 午夜
    • Mastercard：每日 UTC 22:00
  4. 端点： POST /payments
    • source.type = currency_account

必填字段

  • Currency Account ID（ca_）— 用作 /payments 端点中的 source.id 字段。可在控制台（实体Entity层级）→ Business account → Balances中找到。点击货币账户Currency Account上的 … 图标以打开账户详情弹窗。
  • Entity ID（ent_）— 用于 /balances 端点。可在 控制台（实体Entity层级）→ Settings（右上角）→ 账户详情Account details中找到。

在 /payments 端点中：

  • instruction.funds_transfer_type：
    • Visa 为 FD/FT/LA
    • Mastercard 为 C52/C55
    该值在沙盒与生产环境中可能不同。
  • processing_channel_id — 可在控制台 → 设置（右上角）→ 设置 → 业务设置 → 处理通道中找到。
  • destination.account_holder.type = individual
  • 资金转账（FT/LA/C52）需要 sender — 发送方即用户：
    • sender.type = individual
    • sender.first_name = 用户的名字
    • sender.last_name = 用户的姓氏
    • sender.address = 用户的账单地址
    • sender.reference
    • sender.reference_type = other
    • sender.source_of_funds = debit

境内与跨境

沙盒环境中已启用所有国家或地区，但对于生产环境，请参考我们提供的国家或地区清单。

  • 当实体的注册国家或地区与收款人发卡行国家或地区相同时，卡片提现为境内。
  • 当实体的注册国家或地区与收款人发卡行国家或地区不同时，卡片提现为跨境。

[生产环境] 内部校验

  1. 非资金转账（发送方为商户）：检查收款人发卡行国家或地区是否属于目的地国家或地区清单（参见国家或地区清单 Excel — 将由 CKO 团队提供）。
  2. 资金转账（发送方为用户）：检查收款人发卡行国家或地区是否属于目的地国家或地区清单，并检查发送方账单国家或地区是否属于发送方国家或地区清单（参见国家或地区清单 Excel — 将由 CKO 团队提供）。

货币

有两种关键货币需要了解。

货币类型 说明 支持的货币
持有货币 Checkout.com 从商户处接受、用于为 Pay to Card 交易注资的货币。这些将是商户在 Checkout.com 持有的货币账户的货币 Checkout.com 目前接受 GBP、EUR、USD
处理货币 卡组织可通过当地发卡银行向收款人提供的货币 目前接受100+ 种货币。
