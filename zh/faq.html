常见问题

商户在接入过程中最常问到的问题解答。

如何查看交易状态以及失败原因？

您可以在两个地方查看 — 控制台和 API。

控制台：打开支付页面，按支付 ID 搜索。将鼠标悬停在 响应码 上即可查看状态，打开支付详情页面可查看完整明细。

API：每次支付请求的 API 响应中都会返回相同的响应码。

我的财务团队应如何与 Checkout.com 对账？

请遵循我们的 对账指南， 其中详细说明了如何将结算和付款与您已处理的支付进行匹配。

如何提交支持工单？

登录控制台，点击右上角的问号图标，然后选择 Request support（请求支持）。

如何创建 API 密钥？

登录控制台，在左侧菜单栏选择 Developers（开发者） 板块，点击 Keys（密钥），然后选择 创建新密钥。详情请参阅 开发者文档。

如何设置单点登录（SSO）？

您可以在控制台中为您的团队配置 SSO — 请遵循 SSO 设置指南。

如何查看和更新我的企业信息？

您可以直接在控制台中查看和更新您的企业信息。请参阅 管理企业信息。

如何获取报告？

Checkout.com 提供一系列报告，助您开展业务运营并获取洞察。您可以通过四种方式 获取这些报告：

  • 在控制台中按需或按计划生成并下载报告。
  • 使用报告 API 以编程方式获取报告。
  • 通过安全文件传输协议（SFTP）访问报告。
  • 通过 webhook 接收定期报告。

设置说明请参阅 获取报告。

我可以设置定期付款吗？

可以。您可以使用客户已存储的卡片信息对其进行定期扣款 — 请参阅 使用已存储卡片信息的定期付款。

我的上线前检查清单应包含哪些内容？

在开启实时流量之前，请确认您的技术集成和配置已达到生产就绪状态：

  • 激活控制台：确保您的控制台已激活，并且团队中相关人员拥有访问权限。
  • 更换 API 密钥和端点：将您的环境配置从沙盒切换到生产环境。用控制台中生成的正式生产环境密钥替换所有测试用的公钥和密钥。
  • 配置正式环境 webhook：在您的正式环境中重新创建所有系统关键的 webhook。确保您的服务器监听诸如 card_verified、payment_approved、payment_declined、payment_captured、payment_refunded 和 payment_voided 等实时事件，并确保您的正式端点已加密且经过认证。
  • 启用 3D Secure（3DS）和欺诈规则：在控制台中检查您的 3DS 规则。确认在强制要求强客户认证（SCA）的地区（例如欧洲）已启用并正确配置 SCA，以避免发卡行立即拒付。
  • 配置报告方式：为财务对账设置您的报告渠道（控制台、API 和 SFTP）。
  • 确保良好的数据质量：确认每次请求都传递了足够的信息以保证数据质量，并在适用情况下满足 AFT 强制要求（可选）。
  • 运行生产环境冒烟测试：
    1. 处理一笔真实交易。使用一张真实的个人或企业卡片购买一件低价的实时商品。请勿使用沙盒卡片 — 它们在生产环境中会立即失败。
    2. 验证 webhook 响应。监控您的后端日志，确认您的系统捕获到实时事件，并将订单状态从“待处理”变更为“已支付”。
    3. 触发部分或全额退款。从您的平台后端或控制台发起退款，以确认反向支付流程能够端到端正常运作。
